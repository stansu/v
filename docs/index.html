任務

    只下載你有權取得的內容；請遵守各平台條款與當地著作權法。 怎麼設定？

    設定步驟

    1. Fork 這個 repo，或把整個專案推到你自己的帳號。
    2. Repo → Settings → Pages → Source 選 Deploy from a branch，資料夾挑 /docs。
    3. Settings → Actions → General → 確認 Actions 允許執行。
    4. 個人頭像 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token：只選這個 repo，權限給 Actions: Read and write。
    5. 回到本頁，把 owner、repo、token 填進「連線設定」，按「測試連線」。

    Token 有風險：拿到它的人可以觸發這個 repo 的 workflow。用完可按「清除 token」，或到 GitHub 撤銷。
